# 江苏省张家港中等专业学校 · 三维虚拟校园

依据学校总平面图 1:1 复原的交互式三维校园导览，纯静态站点，无需构建、无框架、无后端。

- 在线访问：https://gedongyou.github.io/campus-3d/
- 仓库地址：https://github.com/gedongyou/campus-3d

## 这是什么

把学校的**总平面图**转成可以转、可以点、可以飞的三维模型：

- **17 栋建筑**按图纸的多边形轮廓挤出墙体，层数与高度取自图上标注（如教学楼 5 层 20.56 米、宿舍 12 层 47.5 米）。
- **道路、跑道、水系**按图布置：400 米标准跑道（红色塑胶面 + 8 条分道线 + 足球场）、匠心湖（折线栈桥 + 湖心岛 + 东岸月牙平台）、两个校门（实训区高门架 / 学校主入口柱廊）。
- **点楼看详情**：分区、楼层、高度、占地、简介、开设专业、馆内点位。

## 技术要点

| 项 | 做法 |
| --- | --- |
| 渲染 | Three.js r160+（`vendor/three.module.js`，通过 importmap 引入），PCFSoft 阴影 + ACESFilmic 色调映射 |
| 几何 | 多边形沿边生成竖直墙带（`wallBand`），三角化水平面（`fillPoly`），环形条带（`ringBand`）；任意凹多边形都正确 |
| 立面 | Canvas 程序化贴图，一个贴图单元 = 一开间 × 一层（`tileH = (h - 基座高) / 层数`），12 层与 3 层共用贴图不变形 |
| 道路 | 所有路面矩形做并集贪心合并，一次性写成单张几何 → 路口不存在共面重叠 |
| 深度 | `logarithmicDepthBuffer` + `near = 4`，解决远距离路面被草地吞掉 |
| 性能 | 无外部贴图、树木/路灯/栏杆全部 InstancedMesh、贴图按材质缓存、像素比上限 2 |

## 目录

```
index.html            页面骨架与 UI
css/style.css         玻璃拟态浅色界面，移动端自适应
js/config.js          校名、校训、7 个预设视角
js/plan.js            由总平面图生成的数据（楼栋多边形/道路/跑道/水系），勿手改
js/main.js            场景、几何、交互、UI 逻辑
vendor/               本地 Three.js 与 OrbitControls
```

## 本地运行

```bash
python3 -m http.server 8088
# 打开 http://127.0.0.1:8088
```

也可以直接丢到任意静态托管（GitHub Pages / OSS / Nginx）。

## 说明

楼栋位置、平面轮廓、层数与高度取自学校总平面图；外立面材质、树木、路灯等大尺度配景为示意处理，用于空间认知与导览演示，不作为工程图纸使用。
